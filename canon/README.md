# Canon

The only source of creative truth for *Search for the Godtree*. If a comment, an issue or an asset disagrees with the canon, the canon wins until the lead changes it.

**Status: approved by the owner on 2026-10-09** ([decisions/0008](../decisions/0008-canon-approved.md)). Later zones in the world bible are sketches and will change.

| File | What it settles |
|---|---|
| [vision.md](vision.md) | What the game is and is not |
| [pillars.md](pillars.md) | The five design pillars every decision is tested against |
| [world-bible.md](world-bible.md) | The world, its people, its words, its zones |
| [art-bible.md](art-bible.md) | The look, and the budgets that enforce it |
| [audio-bible.md](audio-bible.md) | The sound |

## How the canon changes

- Anyone may propose a change by opening a proposal issue (see [proposals/README.md](../proposals/README.md)).
- Only the lead edits these files. Changes to the pillars need the owner's approval.
- Every change is recorded in [decisions/](../decisions/) with its reason.
- Numbers (triangle counts, texture sizes, names, palette) live in [data/budgets.json](../data/budgets.json), which the automated checks read. The art bible explains them; the data file enforces them.
