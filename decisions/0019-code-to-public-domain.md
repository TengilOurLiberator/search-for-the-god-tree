# 0019: Code moves to the public domain

- **Date:** 2026-10-11
- **Decided by:** Owner
- **Replaces:** the code half of [0002](0002-licences.md). The asset half (CC0 1.0) stands.

**Decision.** The project's code is released under the Unlicense, a public-domain dedication, in place of MIT. With assets, recipes, documentation and canon text already CC0 1.0, everything the project owns is now free for anyone to use, change, share and sell, with no conditions and no credit required.

**Reason.** The owner wants the game free to use for everyone, as their other project is. MIT's one condition, keeping the copyright notice, is bookkeeping nobody here wants.

**Why this could be done.** All code in the repository up to this decision was written by the lead for the owner; no outside code has been merged, so nobody else's agreement was needed. From now on contributors give their code on these terms (AGENTS.md).

**What it does not change.**
- Copies already taken under MIT stay usable under MIT.
- Third-party packages, engines, tools and models keep their own licences and are still never copied in (THIRD_PARTY_LICENCES.md). Unity itself is not open source.
- Only CC0 material may be folded into assets (decision 0007). MIT-licensed code from elsewhere may no longer be pasted into the project's code without keeping its notice in a folder of its own; ask the lead first.
- The Unlicense and CC0 give up copyright; they grant no trademark or patent rights and carry no warranty.

**Affects.** `LICENSE`, `LICENSE-ASSETS.md`, `data/licences.json`, AGENTS.md, README.md, ROADMAP.md, THIRD_PARTY_LICENCES.md.
